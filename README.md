# Computer Vision Projects

A collection of beginner-friendly computer vision projects built using Python, OpenCV, and modern object detection models. Each project demonstrates a practical real-world application that can be implemented using publicly available datasets or stock video footage.

## Projects

### 1. Parking Lot Spot Finder

Detects vehicles in parking lots and determines whether parking spaces are occupied or available.

Features

- Vehicle detection
- Parking space occupancy detection
- Available parking counter
- Real-time visualization
- Parking analytics dashboard

Run

```bash
python parking_lot_spot_finder.py
```

---

### 2. Highway Speed Estimation

Estimates vehicle speeds from highway footage using object tracking and calibrated distance measurements.

Features

- Vehicle detection
- Multi-object tracking
- Speed estimation
- Speed limit violation detection
- Real-time overlays

Run

```bash
python highway_speed_estimation.py
```

---

### 3. Wrong-Way Driver Detector

Detects vehicles moving against the expected traffic direction and identifies potential lane violations.

Features

- Vehicle detection
- Vehicle tracking
- Lane direction analysis
- Wrong-way detection
- Violation alerts

Run

```bash
python wrong_way_driver_detector.py
```

4. Vision-Based Lane-Level Navigation
Understands lane geometry and generates navigation guidance for autonomous driving.

Run

```bash
python lane.py
```

---

### 5. Trash Detection System

Detects litter and waste objects in parks, streets, and other public environments.

Features

- Trash detection
- Public area monitoring
- Object localization
- Real-time visualization
- Environmental analytics

Run

```bash
python trash_detection.py
```

## Installation

Clone the repository.

```bash
git clone https://github.com/tubakhxn/computer-vision-projects.git

cd computer-vision-projects
```

Install the dependencies.

```bash
pip install -r requirements.txt
```

Run any project by navigating to its folder or executing the corresponding Python script.
